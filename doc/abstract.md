# FUN HOUSE: A Surreal Dream-like Escape-Room Game made in Godot
Presenters: Russell R. Cannon, Bernardo Mejia, Patrick Murphy, Heriberto Dominguez

FUN HOUSE is a simple 3D escape-room game where the player's goal is to escape a nonsensical "house". The game makes use of 2D sprites in a 3D environment to ensure the game stays within scope. Rooms and keys are up to developer interpretation during development, each key differs in some way but always has the same function: Allow the player to progress to the next room.

The goal was to provide the player with a sense of alienation and mystery; every room was designed with the idea of the games setting being a nightmare. Progression is designed to be linear with some minor puzzle elements, meant to keep within scope while providing a layer of interactivity to the player.

Developed in GODOT v.4.7.2, using C# for game logic and GDShader for shading and graphics. Art and 3D models designed in Aseprite and Blender. Sounds produced in Audacity. Communications were handled through Discord. Project tasks and bug reports were handled through GitHub issues. In keeping our project on track and within design limitations, we utilized GitHub Projects and a Game Design Document.
